# 工序: 左侧文件抽屉(树形目录)与目录模式

## 需求

1. **文件抽屉**: 左侧增加一个向外伸出的抽屉,展示当前打开文件所在文件夹的
   树形目录(文件夹/文件图标,只过滤出能展示的 .md 文件);展开时若整个窗体
   超出屏幕宽度,则把窗体尺寸控制到屏幕宽度以内。
2. **目录模式**: 支持参数只传一个目录(CLI `--args <目录>`),此时右侧窗体
   空白,左侧是树形目录清单。
3. **同窗覆盖打开**: 左侧双击文件后在右侧阅读窗格打开(不新开实例);若当前
   文档有修改,先提示是否保存(保存/取消/不保存),确认后直接覆盖打开新文件。

## 已确认决策(2026-10-20 用户定稿)

- 目录模式右侧「空白」= **空白编辑器**(复用现有空文档路径,可直接打字,
  ⌘S 走另存为);否决「只读占位」(需 web 层只读开关,改动面不成比例)。
- **增加「文件 → 打开文件夹…」菜单入口**,与 CLI 参数、拖入目录共用同一条
  openDirectory 路径。

## 组件设计(修改方案)

```
AppDelegate ──CLI目录/拖入目录/打开文件夹菜单──▶ DocumentWindowController
                                                     │ 1:1
                     ┌───────────────────────────────┼────────────────────┐
                     ▼                               ▼                    ▼
             FileDrawerView(新)                EditorWebView(不动)    statusBar(不动)
             树形UI+开合动画+双击回调
                     │ 契约: onOpenFile(URL)
                     ▼
             DirectoryTree(新,纯逻辑,无状态)
             目录扫描+md过滤(扩展名单源复用 AppDelegate.markdownExtensions)
```

### 外部契约调整

1. CLI 裸参数从「仅文件」扩展为「文件或目录」:目录 → 目录模式窗口(原被静默忽略)。
2. 视图菜单新增「文件抽屉 ⌘\」开合项;文件菜单新增「打开文件夹…」。
3. openDocument 脏确认从模态「丢弃并打开/取消」统一为 beginConfirmClose 的
   sheet「保存/取消/不保存」(与关闭确认同一路径,消灭"静默丢弃"语义)。

### 组件间关系

- DocumentWindowController 1:1 持有 FileDrawerView(随窗口生死)与目录模式状态。
- DirectoryTree 无持久状态:权威数据在磁盘,抽屉只是扫描投影;刷新动作单点 rescan。
- 树双击/菜单/拖放/最近文件/文档内链接全部收敛到 openDocument(at:) 单一装载路径。

### 明确不受影响(兼容承诺)

- JS 桥协议、web 层、导出、文件监视、外观切换、既有打开路径的文件语义。

### 性能与边界

- 目录扫描后台队列执行,代际计数防过期结果回灌;条目总数与递归深度设上限防挂起。
- 不跟随符号链接(防环);跳过隐藏条目;不含 .md 后代的目录不展示。
- 抽屉宽度固定 240pt;开合状态 UserDefaults 记忆;目录模式由 fileURL=nil 表达。

## 验收标准

1. ⌘\ 开合抽屉;树含文件夹/文件图标与层级,只显示可展示 .md(markdownExtensions
   全部扩展),隐藏条目跳过,无 .md 后代的目录不出现。
2. 展开时窗口优先向左伸出 drawerWidth;伸出后超出屏幕可视宽度则整体收敛到
   屏幕宽度;收起反向还原(下限窗口 minSize)。
3. `open dist/MDPreview.app --args <目录>` → 目录模式:标题为目录名、右侧空白、
   抽屉展开显示树;「打开文件夹…」/拖入目录同路径。
4. 双击树中文件:脏→sheet 保存确认(保存/取消/不保存),确认后同窗口覆盖打开
   (documents 数量不变);不脏→直接覆盖打开;抽屉选中行同步。
5. selftest 全绿(含新增 DirectoryTree 扫描用例);--multiwindow-test 不回归;
   --drawer-test(新增)通过。

## 设计决策变更(2026-10-20 用户实测反馈)

- **现象**:打开本仓库 README.md,抽屉不显示 doc/。根因:web/node_modules
  有 17,410 条目,把 8000 枚举预算在 readdir 顺序中提前耗尽,靠后的兄弟目录
  (doc/samples 等)全被截断。
- **修正**:`node_modules` 与包目录(.app/.bundle 等,Finder 同款不透明语义)
  在递归入口**整棵跳过**(内部条目不进枚举,预算不再被无关子树吃掉);
  枚举预算 8000 → 20000。「无 md 后代目录剪枝」规则保持不变。

## 设计决策变更 2(2026-10-20 用户定稿:lazy 按层装载)

- **决策**:改为 lazy 模式——每次只装载当前层,展开目录时触发下一层读取
  (Finder/Typora/VS Code 文件树同款模型)。单层 readdir,任意规模目录树
  开销恒定,从结构上消灭截断问题,不再需要枚举预算/深度限制。
- **语义取舍**:lazy 下不读到子层就无法知道后代有没有 md,**放弃**
  「无 md 后代目录剪枝」——所有非隐藏目录都显示(含暂无 md 的目录,展开为空),
  文件仍只列可展示 md;node_modules/包目录跳过保留(此时是纯噪音过滤)。
- **实现要点**:点击展开走 shouldExpand 拦截 + 后台装载续展(不阻塞主线程);
  选中定位走祖先链同步装载(低频动作,每层 readdir 毫秒级);重扫 = 重读
  根层 + 展开态按需重读(天然回到磁盘现状)。

## 边界(本工序不做)

- 目录内容的自动监听(手动刷新按钮 + 展开时重扫;FSEvents 目录监听另立工序)。
- 树内新建/删除/重命名文件操作。
- 抽屉宽度拖拽调节(固定 240pt)。
- 非文本附件类型展示(过滤谓词单点在 DirectoryTree,扩展另立工序)。
