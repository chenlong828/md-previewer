# 工序: 抽屉锚点控件改版与宽度拖拽调整

## 需求(2026-10-22 用户提出)

1. 抽屉头部的根目录选择下拉框更漂亮:菜单项带**与 Finder 一致的文件夹图标**;
   控件宽度 = **抽屉宽度减去刷新按钮宽度后的剩余空间**(刷新按钮保留在头部右侧)。
2. 抽屉与 Markdown 文档之间的间隔处可用鼠标拖拽,动态调整二者宽度。
3. 刷新按钮左边增加 **Home 按钮**,一键返回当前用户的 Home 目录;根目录选择框
   再相应减少对应宽度(控件宽度 = 抽屉宽 − Home − 刷新 − 两处间距)。

## 已确认决策(2026-10-22 用户定稿)

- **Home 放锚点框右侧**(答案:右侧更好)——左侧是「身份位」(锚点框图标须与树内
  文件夹图标同列、名称贴抽屉左缘),右侧是「动作位」;有状态控件与无状态动作分组,
  Home/刷新同在动作组;仅当以后增加「上一级/后退」时,才拆成「导航左 / 工具右」两组。
- **两个图标按钮间距 4pt**(Home 换根有观感代价,不与刷新挤在一起)。

## 现状与落点

- 现状:头部是 borderless `NSPopUpButton`(控件宽度只包住文字、菜单项只有文字无图标、
  层级靠 `indentationLevel` 缩进);抽屉宽度固定 `FileDrawerView.width`(240pt),边界不可拖。
- 落点:
  - 新 `DrawerAnchorControl`(自绘):铺满头部扣除 Home/刷新两个按钮后的空间,
    药丸底 + 文件夹图标 + 当前目录名 + 展开箭头;菜单为根 → 当前的平坦父级链,
    每条带同款图标、当前项勾选(与 Finder 标题栏路径菜单同构,取代「面包屑缩进」)。
  - 新 `FinderIcon`:树与锚点菜单共用的「与 Finder 一致」图标单点(按真实路径取
    系统图标,复制后缩放到目标边长)。
  - 头部新增 Home 按钮(`homeDirectoryForCurrentUser`,已在 Home 时置灰)。
  - 新 `DrawerResizeDivider`:横跨抽屉/编辑器边界的 8pt 透明热区,中间 1pt 竖线,
    悬停/拖动时线条加强,左右拖拽光标。
  - `DocumentWindowController`:抽屉宽度由常量改为状态(夹取 160–480,且正文 ≥ 320),
    `UserDefaults["fileDrawerWidth"]` 记忆;开合动画与窗口伸缩用**当前**宽度。

## 契约调整

- 外部契约:锚点回调 `onAnchorSelected(URL)` 语义不变;菜单条目集合不变(仍是
  锚点到文件系统根的父级链),只改呈现形态。诊断面 `anchorItemCountForDiagnostics`
  语义不变(条目数)。
- 组件间关系:新增 divider 视图夹在 drawer 与 webView 边界之上(仅 AppKit 布局层,
  不进 web 层);drawer 宽度从常量变可变状态,开合/窗口宽度收敛改读该状态;
  新增持久化键 `fileDrawerWidth`(全局,与 `fileDrawerVisible` 同口径)。
- 明确不受影响:JS 桥协议、web 层、导出/打印、文件监视、双击覆盖打开、重锚语义、
  目录模式语义。

## 验收场景

1. **锚点控件**:目录模式下头部控件铺满「抽屉宽 − Home − 刷新 − 间距」,显示 Finder
   文件夹图标 + 当前目录名 + 展开箭头;点击弹出父级链菜单(每条带文件夹图标/当前项
   勾选);选父级 → 抽屉切根,`anchorItemCountForDiagnostics` = 父级链长度(既有重锚
   断言不回归);Home 按钮切回 Home 目录并置灰。
2. **边界拖拽**:抽屉展开时拖动边界,抽屉宽度实时变化(160–480,正文不窄于 320),
   窗口宽度不变;松手后再拖从当前宽度续算。
3. **宽度记忆**:收起抽屉时窗口按当前宽度缩回,重新展开恢复该宽度;`fileDrawerWidth`
   落盘,重启后恢复;抽屉收起时边界不可拖(无拖拽光标)。
4. **头部宽度账**(drawer-test):锚点控件贴左缘且右缘 = Home 左缘 − 4、Home 右缘 =
   刷新左缘 − 4、刷新贴右缘 − 6,控件宽度 = 抽屉宽 − 两个按钮 − 两处间距(按对齐矩形
   断言,不吃 NSButton 的 alignmentRectInsets 半像素差);菜单每条都带 Finder 图标。

## 非目标

- 不改 web 层、不加文件系统监听、不加目录增删改名、不做多抽屉。
