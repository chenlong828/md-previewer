# REQ-0014：文件抽屉显示隐藏文件与隐藏目录

**类型**：feature

## 1. 场景叙述

用户打开一个目录（或含抽屉的文档窗口），在抽屉头部点「显示隐藏文件与隐藏目录」按钮，
树里立即出现 `.git`、`.github`、`.config` 这类隐藏目录与 `.env.example` 这类隐藏文件；
再点一次恢复隐藏。开关状态跨窗口同步、重启后保持。

结果：在项目里查隐藏配置、隐藏文档或 `.github/workflows` 下的 Markdown 不必切到 Finder
或命令行。

## 2. 价值

不做的后果：抽屉只显示非隐藏条目，项目约定放在点目录里的文档与配置无法从应用内浏览；
用户必须切到 Finder（⌘⇧.）再回到应用，或改用命令行查找。

## 3. 非目标

- 不做「隐藏文件」「隐藏目录」两个独立开关；一个开关同时管两类。
- 不改变可打开文件过滤：隐藏条目里仍只列 Markdown 与代码文件。
- 不放开 `node_modules`、包目录（`.app`/`.bundle` 等）与符号链接的跳过规则。
- 不做每个窗口/每个目录独立记忆；偏好是全局单值。
- 不改变树排序、展开策略、空态文案、锚点/重锚与双击打开语义。
- 不提供主菜单/快捷键入口（仅抽屉头部按钮）。

## 4. 行为约定

- 隐藏口径与 Finder 一致：`.` 开头的条目，或 Finder 隐藏标记（`URLResourceValues.isHidden`，
  含 `chflags hidden`）。
- 抽屉头部按钮：`eye.slash` = 当前不显示隐藏条目（点击显示）；`eye` = 当前显示（点击隐藏）；
  显示状态用强调色。悬停提示随状态变化。
- 偏好键 `UserDefaults["fileDrawerShowsHidden"]`，默认 false；切换后写盘并广播所有窗口。
- 切换立即重扫当前根层；可见目录的展开态保持不变。
- 新窗口（含目录模式）按记忆值初始化；未装载根的窗口只同步按钮状态。
- 隐藏条目里不可打开的文件（如 `.gitignore`、`.env`）仍不进树；隐藏目录可展开，
  其内部按同一可打开文件过滤。

## 6. 验收

验收 = SCN-0020 `verified` + §4 约束未被违反。

自动化：

- `--selftest`：「目录扫描-显示隐藏(Finder 标记也识别,噪音仍跳过)」「目录扫描-隐藏目录可展开读子层」
  「抽屉-显示隐藏 默认只显示可见条目」「开:…偏好落盘」「关:…偏好复位」「偏好记忆对新窗口生效」。
- `--drawer-test`：头部三按钮几何（锚点控件宽度账）、开关默认关/打开落盘/关闭复位。
- `--multiwindow-test`：「抽屉显示隐藏开关跨窗口同步(开)」「…(关)」。

人工：真实点击按钮观察树变化与跨窗口同步（本次构建后确认）。

## 7. 澄清记录

- 2026-11-13 用户要求：在左侧文件抽屉增加按钮开关，切换是否显示隐藏文件/隐藏目录。
- 2026-11-13 三选一确认：隐藏口径 = Finder 口径；开关状态 = 全局记忆；按钮位置 = 抽屉头部图标按钮。
- 默认口径：隐藏条目里仍只列可打开文件；`node_modules`/包目录/符号链接继续跳过。
