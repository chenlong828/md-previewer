# REQ-0012：文档右键拷贝文件路径

**类型**：feature

## 1. 场景叙述

用户打开一个已保存的 Markdown 或代码文件，在正文上右键，选择「拷贝文件路径到剪贴板」，当前文件的绝对路径写入系统剪贴板，可直接粘贴到终端、Finder、聊天窗口或脚本里。

未保存的新文档和目录模式没有文件路径，菜单里不出现该项。

## 2. 价值

不做的后果：只能从标题栏、Finder 或打开面板间接获取路径，或按目录手动拼接；频繁引用同一文件路径时操作链路过长且易错。

## 3. 非目标

- 不做「点击标题栏文件名拷贝路径」（2026-11-05 已否决自绘标题栏方案，见澄清记录）。
- 不做相对路径、`file://` URL、文件名、shell 转义等格式选择。
- 不把命令加进菜单栏；只进文档右键菜单。
- 不为未保存文档或目录模式伪造路径。
- 不写文件、不产生脏标记、不改文档内容。
- 不做拷贝成功的 toast/弹窗。

## 4. 行为约定

- 菜单项固定为「拷贝文件路径到剪贴板」，位于文档右键菜单剪贴板命令组之后、查找命令之前。
- 仅当窗口对应一个已保存文件时出现；Markdown 与代码文档都出现。
- 写入当前文件的绝对 POSIX 路径：百分号解码，无 `file://` 前缀。
- 未保存文档 / 目录模式：菜单项不出现；也不写入空串或伪造路径。
- 只写系统剪贴板；不写文件、不产生脏标记、不影响撤销栈。
- 不做拷贝成功的 toast/弹窗。

## 5. 影响场景

| 场景 | 状态 | 本次新增/修改的断言 |
|---|---|---|

受影响行为：文档右键菜单、剪贴板。不影响文件 IO、编辑、保存、导出、缩略图、抽屉、标题栏。

## 6. 验收

验收 = SCN-0018 `verified` + §4 约束未被违反。

自动化：

- `--multiwindow-test`：Markdown/代码两个文档的菜单项 2/2、路径精确写入、未保存文档不显示且不拷贝。
- `--selftest`：命令注册表完整（含 `copyFilePath`），无响应缺失。

人工：2026-11-05 用户确认右键菜单项可见、点击后路径正确。

## 7. 澄清记录

- 2026-11-05 用户提出：点击左上角文件名拷贝当前文件全路径。实现为自绘标题栏后，用户认为太复杂，要求整体回滚。
- 2026-11-05 用户改为：在文档右键菜单增加「拷贝文件路径到剪贴板」。本卡按此落地。
- 2026-11-05 未保存/目录模式没有文件路径：不显示该项，不伪造字符串。
